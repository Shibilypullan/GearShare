# **App Name**: GearShare – Campus Marketplace

## Core Features:

- User Authentication & Profiles: Secure user registration, login, social authentication (Google, Apple), and management of user profiles including Trust Score and transaction history.
- Item Listing & Availability: Users can post items for rent with photos, detailed descriptions, category selection, flexible pricing (per day or free), and specify item availability using a calendar.
- Item Description Assistant: An AI tool that suggests and refines item descriptions based on the item name and category, helping users create compelling listings.
- Browse, Search & Filtering: Explore items via a scrollable feed, search for specific items with keywords, and filter listings by category (e.g., Books, Calculators) or location on a map.
- Secure Borrowing Workflow: Users can view item details, check availability, and initiate borrow requests. The system generates unique QR codes/Verification IDs for secure, trackable item handovers.
- Real-time Messaging: Facilitate direct, real-time communication between borrowers and item owners to coordinate exchanges and clarify details.
- Interactive Campus Map: Visualize available items as pins on a campus map, with search and filtering capabilities, to discover resources based on proximity.

## Style Guidelines:

- Primary Color: #194580 (a deep, reliable blue). This hue evokes trust, professionalism, and an academic sensibility, serving as the main color for branding, important buttons, and navigation elements. It ensures critical UI components are easily identifiable.
- Background Color: #ECF0F6 (a subtle, cool off-white). This heavily desaturated variant of the primary color creates a clean, open canvas for content, providing a light, airy, and contemporary feel suitable for readability and a modern application interface.
- Accent Color: #23AFC4 (a vibrant turquoise). Chosen as an analogous complement to the primary blue, this brighter and more saturated hue is reserved for active states, calls to action (CTAs), and highlighting interactive elements to draw user attention effectively without clashing with the primary aesthetic.
- Font Family: 'Inter' (sans-serif) for all text. Its modern, objective, and neutral aesthetic ensures excellent readability and a consistent professional appearance across headlines and body content, aligning with the app's practical and trustworthy nature.
- Use a set of simple, outlined icons with a consistent line weight for all UI elements, including navigation, categories, and feature-specific indicators (e.g., notification bell, share, back arrows, profile).
- Adopt a mobile-first, single-column layout optimized for easy scanning and interaction on small screens. Content sections should utilize card-based structures for listings and informational blocks, enhanced with persistent bottom navigation and horizontally scrollable sections for categories and trending items.
- Implement subtle, fast, and smooth transitions for screen changes and UI element interactions, such as taps, hovers, and data loading states. Animations should feel responsive and aid in conveying visual hierarchy and feedback without distracting the user.
